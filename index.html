Model Fit Test

Your task, your rules. Run it on the new model. See if it fits you.

A new model is out and everyone says it is great. Whether it is good enough depends on your work. This page builds a short test from your own tasks. You run it in your own chat app and read the verdict. It works for any model.

This is a quick check on your own tasks, not a benchmark. See how a model handles your real work first, then decide if it is worth rebuilding any workflows around.

Run the test

  1. Open Claude and start a new chat.
  2. In the model picker, make sure the model you want to test is selected.
  3. Paste this prompt and send it.
  4. Read the stamp at the end of the reply. A model grading itself leans generous, so treat a FIT as promising. Switch to Strict for a harder check.
  5. Wait for the three answers, then go on to the review step below.
  6. Repeat in a second new chat on your usual model with the same prompt.
